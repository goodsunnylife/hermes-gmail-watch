Hermes Gmail Watch プライバシーポリシー

1. 取得する情報

本ツールは、Google アカウントの所有者本人が許可した場合に限り、その本人の Gmail のメール（本文・添付ファイル・送信者・日時）を読み取ります。

2. 利用目的

読み取った情報は、所有者本人の経理作業（領収書の整理など）にだけ使います。

3. 第三者への提供

取得した情報を、第三者に提供・販売・共有することはありません。

4. 保存と管理

情報は所有者本人のPCと、本人の管理するクラウドストレージにだけ保存します。

5. 許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス許可を取り消せます。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。
